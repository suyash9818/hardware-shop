Authentication

The current API is already working without an API key.

This project is configured with AllowAny, so the data endpoints are publicly accessible right now. JWT and token endpoints exist, but they are not required for the current API routes.

How To Check

Open /api/ in the browser to see the endpoint index.

Open any list endpoint like /api/products/ or /api/orders/ to confirm it returns JSON.

For write checks, send a POST request from Postman, curl, or the DRF browsable API form.

Example Requests
GET  /api/products/
GET  /api/orders/
POST /api/orders/
POST /api/orders/1/submit/
